※ 가상환경 만들기(ml-dl-nlp / llm)

현재 존재하는 가상환경 목록 확인
conda env list
conda info --envs

가상환경 생성;-n은 --name
conda create n ml dl nlp python=3.10
conda create -n ml-dl-nlp python=3.10

생성된 가상환경으로 들어가기
conda activate ml-dl-nlp

가상환경 나오기
conda deactivate

가상환경 지우기
conda env remove name 가상환경이름

※ 환경설정 3. 가상환경을 jupyter에서 선택가능한 커널로 등록

가상환경에 들어가서 jupyter 설치
conda install ipykernel

Jupyter에서 선택가능한 커널로 등록
python -m ipykernel install --user --name ml-dl-nlp --display-name "ml-dl-nlp(ipykernel)"

Jupyter 커널 목록 확인
jupyter kernelspec list

Jupter 커널 목록에서 삭제
jupyter kernelspec remove display이름

Jupyter lab 실행
Jupyter lab –-notebook-dir=d:\ai\source\05_DeepLearning
jupyter lab --notebook-dir="c:\ai\source\05_DeepLearning"
