Oracle SQL 데이터 조회


1  조회 흐름

테이블 지정 → 조건으로 행 선택 → 필요한 열 선택 → 정렬
SELECT → 조회할 열을 지정한다.
FROM → 데이터를 가져올 테이블을 지정한다.
WHERE → 조건에 맞는 행만 가져온다.
ORDER BY → 조회 결과를 정렬한다.


2  핵심 용어

열 column → 하나의 항목, 행 → 한 건의 데이터
* → 모든 열 선택
alias → 조회 결과의 열 등에 붙이는 별칭
DISTINCT → 선택한 열의 값이 같은 중복 행을 제거한다.
condition → 열, 표현식, 상수, 비교 연산자로 만든 조건
ASC → 오름차순이며 기본 정렬 방향
DESC → 내림차순
