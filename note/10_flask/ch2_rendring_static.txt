Flask  프로젝트 구조와 웹 실행 흐름


1절  웹 실행 흐름

주소 요청 → Flask의 처리 함수 실행 → 필요한 데이터나 모델 사용 → HTML 또는 데이터 응답
Flask는 Python으로 웹 요청을 처리하는 도구다. 모델의 예측 결과도 웹 화면으로 전달할 수 있다.


2절  폴더와 파일의 역할

.venv → 프로젝트별 라이브러리를 분리하는 가상환경
app.py → 웹 애플리케이션과 요청 처리 함수를 구성하는 파일
templates → 사용자에게 보여줄 HTML 템플릿
static → CSS, JavaScript, 이미지 같은 고정 파일
model과 predict.py → 저장된 모델과 예측 로직. 웹 요청마다 모델을 다시 학습하지 않고 불러와 사용
requirements.txt → 프로젝트에 필요한 라이브러리와 버전 목록


3절  라우팅과 핵심 기능

라우팅 → 요청 주소와 처리 함수를 연결하는 일
동적 라우팅 → 주소의 일부를 변수로 받아 요청별로 다른 값을 처리
데코레이터 → 함수를 감싸 추가 기능을 적용하는 방식. Flask의 route 등록에 사용
Flask() → 웹 애플리케이션 생성
app.route() → 주소에 처리 함수 연결
url_for() → 함수 이름을 기준으로 주소 생성
app.run() → 개발용 웹서버 실행
