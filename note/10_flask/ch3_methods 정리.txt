전체흐름

사용자 입력
  ↓ GET 요청
Flask에서 request.args로 받기
  ↓
Pydantic 모델로 형식 검증
  ├─ 성공 → 결과 페이지
  └─ 실패 → 오류 페이지


1. GET 요청과 쿼리스트링

<form action="/user" method="get">
    <input name="name">
</form>

전송하면 주소가 /user?name=홍길동 처럼 만들어짐
Flask에서는 request.args로 받음.

HTML의 name="name"
          ↓
request.args.get("name")


2. 회원가입 요청 구조

/join?name=길동&id=123&pw=aa&addr=서울
join.html에서 네 개의 값을 GET으로 보냄.

Flask에서는 각각 꺼냄
↓
name = request.args.get("name")
id = request.args.get("id")
pw = request.args.get("pw")
addr = request.args.get("addr")
↓
Member 객체를 만들고 입력값을 검사함.
member = Member(name=name, id=id, pw=pw, addr=addr)


3. Pydantic 입력 검증

models.py의 Member는 회원 데이터의 규칙표입니다.
↓
class Member(BaseModel):
    name: str = Field(min_length=2, max_length=10)
    id: int = Field(gt=0)
    pw: str
    addr: str = Field(default="서울")
↓
name : 2~10글자
id : 숫자이며 0보다 커야함
pw : 문자열
addr : 입력값이 없으면 서울 출력


4. 검증 성공과 실패 처리

성공시
↓
검증이 끝난 member를 결과 HTML에 전송.
return render_template("1_get/result.html", member=member)
↓
HTML에서는 객체의 속성을 사용함.
↓
{{ member.name }}
{{ member.id }}
{{ member.addr }}

실패시 : 검증 시 오류가 나면 except가 실행됨.
↓
except Exception:
    return render_template(
        "error_page.html",
        error="잘못된 입력"
    ), 500
↓
오류 메시지를 받은 HTML은 경고창을 표시하고 이전 페이지로 back.


5. abort와 오류 처리기

이름이 전달되지않으면 일부로 404 오류를 발생시킴.
abort(404)
↓
발생한 404는 다음 함수가 받으며, 공통 오류 페이지를 보여줌.
↓
@app.errorhandler(404)
def errorhandler(error):
    return render_template("error_page.html"), 404
↓
구조는?

abort(404)
   ↓
@app.errorhandler(404)
   ↓
error_page.html

주의사항
실제 회원가입에서는 비밀번호가 주소창에 노출되는 GET을 사용하면 안 됩니다. 
이번 코드는 GET 처리 원리를 배우는 예제이며, 실제 서비스에서는 비밀번호 같은 정보는 보통 POST로 전송합니다.
