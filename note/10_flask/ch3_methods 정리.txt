Flask  GET 요청과 입력 검증


1절  요청 처리 흐름

폼 입력 → GET 요청 → request.args → Pydantic 검증 → 결과 화면 또는 오류 화면
GET → 요청 주소의 쿼리스트링으로 입력값을 전달하는 방식
쿼리스트링 → URL에 붙는 항목 이름과 값. HTML 폼의 name이 서버에서 값을 찾는 이름이 된다.
비밀번호처럼 민감한 값을 GET 주소에 담지 않는다.


2절  입력값 검증

Pydantic → 입력값이 정해진 자료형과 조건을 만족하는지 검사하는 도구
BaseModel → 데이터 규칙을 정의할 때 사용하는 기본 클래스
Field() → 길이, 범위, 기본값 같은 세부 조건 지정
검증 성공 → 데이터 객체를 HTML 템플릿에 전달
검증 실패 → 예외를 처리하고 오류 메시지 전달


3절  필수 함수

request.args.get() → GET 요청에서 항목 이름에 해당하는 값 읽기
render_template() → HTML 템플릿에 데이터를 넣어 응답 생성
abort() → 지정한 상태 코드의 오류 발생
app.errorhandler() → 오류를 처리할 함수 연결
404 → 요청한 대상을 찾을 수 없음을 나타내는 상태 코드
