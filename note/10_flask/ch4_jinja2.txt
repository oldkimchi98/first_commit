파일 역할

ex.app.py : 이름을 입력받아 목록에 추가 후, 조건문·반복문으로 출력
ex2_quiz.py : 숫자를 입력받아 구구단을 출력 후, 404오류 화면 처리
templates : 데이터가 들어갈 HTML 틀
base.html : 모든 페이지의 공통 구조 (공통 문서양식)
1_index.html, 2_quiz.html : 각 페이지별 내용
header.html : 공통 머리말
footer.html : 공통 꼬리말
static : CSS, 이미지 등
requirements.txt : 필요한 라이브러리와 버전(실행 환경목록)

조건문

{% if name and cnt % 2 == 0 %}
    짝수명({{ cnt }}명)
{% elif name and cnt % 2 == 1 %}
    홀수명({{ cnt }}명)
{% else %}
    총({{ cnt }}명) - 방금 넘어온 이름이 없습니다
{% endif %}
↓
{% ... %} : 조건문·반복문
{{ ... }} : 값을 HTML에 출력
cnt % 2 == 0 : cnt를 2로 나눈 나머지가 0인가?
name and cnt % 2 == 0 : 이름에 값이 있고, 전체 인원수가 짝수라면?
"" : 여기서 빈 문자열은 조건에서 거짓으로 취급
