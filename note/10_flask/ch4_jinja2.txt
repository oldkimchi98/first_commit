Flask  Jinja2와 HTML 템플릿


1절  화면 생성 흐름

폼 입력 → Flask에서 데이터 처리 → HTML 템플릿에 전달 → Jinja2 처리 → 브라우저에 표시
Jinja2는 서버에서 변수, 조건문, 반복문을 처리해 HTML을 만드는 템플릿 도구다.


2절  파일의 역할

templates → 데이터를 넣어 완성할 HTML 틀
base.html → 여러 페이지가 공유하는 공통 문서 구조
header.html과 footer.html → 공통 머리말과 꼬리말
static → CSS와 이미지 같은 고정 파일
각 페이지의 HTML → 해당 화면만의 내용


3절  핵심 처리

request.method → 현재 요청이 GET인지 POST인지 확인
request.form.get() → 폼에서 항목 이름에 해당하는 값 읽기
render_template() → 템플릿에 Python 데이터를 전달하고 HTML 생성
템플릿에서 사용할 이름과 Python 값을 연결해 전달한다.
Jinja2 처리는 서버에서 끝나며 브라우저는 완성된 HTML을 받는다.
