index.html
   │ 회원가입 버튼
   ▼ GET /join
join.html
   │ 입력 후 제출
   ▼ POST /join
Pydantic로 검증
   ├─ 성공 → result.html
   └─ 실패 → join.html로 돌아가 오류 표시
                    │
                    ▼
            PUT /update/...
                    │
                    ▼
              수정 결과 표시

각 페이지가 서로 다른 역할을 담당
index.html : 시작점
join.html : 데이터 입력
result.html : 입력 결과 확인 및 수정
error_page.html : 잘못된 주소 처리

** : 딕셔너리 키와 값을 꺼내서, 함수의 이름표가 붙은 자리로 각각 넣어주는 문법

객체.메서드() : 값이 보유하고 있는 Python 메서드를 직접 실행함.

getElementById() : HTML에서 특정 id를 가진 요소를 찾아오는 JavaScript 함수
addEventListener() : HTML 요소에서 특정 행동이 발생할 때 실행할 함수를 연결하는 JavaScript 메서드
encodeURIComponent () : 문자열을 URL 주소에 넣을 수 있는 형태로 변환하는 JavaScript 함수
