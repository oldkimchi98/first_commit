Flask  POST와 PUT을 이용한 CRUD 흐름


1절  요청의 역할

CRUD → 생성, 조회, 수정, 삭제라는 기본 데이터 작업
GET → 입력 화면이나 데이터 조회
POST → 폼 데이터를 본문에 담아 등록 요청
PUT → 데이터 수정 요청
화면 열기 → 입력과 제출 → 서버 검증 → 결과 확인 → 수정 요청


2절  서버의 데이터 처리

request.form → 폼에서 보낸 입력 데이터
to_dict() → 폼 데이터를 Python 딕셔너리로 변환
** → 딕셔너리의 키와 값을 이름 있는 인수로 풀어 전달
Pydantic 모델 → 전달받은 데이터의 형식과 조건 검사
models.py는 데이터 규칙, filters.py는 화면 출력용 변환을 담당한다.


3절  화면과 서버 연결

fetch() → JavaScript에서 서버로 HTTP 요청 보내기
then() → 비동기 요청의 처리 결과를 받아 후속 작업 연결
addEventListener() → 사용자 동작에 실행할 함수 연결
encodeURIComponent() → URL에 넣는 문자열의 특수문자 인코딩
비밀번호는 방문 기록과 서버 로그에 남을 수 있으므로 URL 경로에 넣지 않는다.


4절  필터와 메서드

필터 → Jinja가 제공하거나 Flask에 등록한 출력 변환 기능
메서드 → 해당 객체가 가진 함수를 직접 실행하는 방식
