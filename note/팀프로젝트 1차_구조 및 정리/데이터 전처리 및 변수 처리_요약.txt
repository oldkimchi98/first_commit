1차 팀플  데이터 전처리와 변수 처리 핵심 요약

여러 상권 자료를 한 표로 합치고, 다음 분기의 폐업위기를 판단할 학습 자료를 만드는 과정이다.
한 행은 특정 상권의 특정 업종을 특정 분기에 관찰한 기록이다.


1절  전체 구조

자료 읽기 → 기준 맞추기 → 표 합치기 → 정답 만들기 → 학습 자료 정리 → 상관분석 → 파생변수

자료 읽기
    2023년부터 2025년까지의 점포와 매출 자료를 이어 붙인다.
    인구, 상권 변화, 위치, 기준금리 자료도 함께 준비한다.

기준 맞추기
    컬럼 이름을 통일하고 상권 코드에 자치구, 행정동, 위경도를 연결한다.
    월별 기준금리는 분기 평균과 전분기 대비 변화량으로 바꾼다.

표 합치기
    추정매출 표를 기준으로 상권, 업종, 분기가 일치하는 자료를 옆에 붙인다.
    인구처럼 업종 구분이 없는 자료는 상권과 분기만 맞춘다.
    배후지 자료는 존재 여부를 표시하고 빈칸은 0으로 채운다.

정답 만들기
    같은 상권과 업종의 다음 분기 폐업 수와 점포 수로 폐업률을 구한다.
    중간 분기가 빠졌다면 다음 행을 바로 다음 분기로 취급하지 않는다.
    폐업률은 전체 점포 중 폐업한 점포의 백분율이다.
    업종 평균은 같은 기준 분기와 업종의 다음 분기 폐업 수 합계를 점포 수 합계로 나눈 백분율이다.

    폐업위기_y1 → 다음 분기 폐업률이 업종 평균을 초과하면 1, 아니면 0
    폐업위기_엄격_y2 → 업종 평균의 2배 이상이고 폐업이 1건 이상이면 1, 아니면 0
    1은 이 프로젝트의 위기 기준에 해당한다는 뜻이며 개별 점포의 폐업 확정은 아니다.

학습 자료 정리
    정답이 없는 2025년 4분기는 예측용으로 남기고, 그 외 다음 분기 누락 행은 제외한다.
    다음 분기 정보와 정답 컬럼은 입력변수에서 제외하도록 따로 기록한다.

상관분석
    입력 행의 분기가 2023년과 2024년인 자료로 변수와 폐업위기의 관계를 살펴본다.
    2025년은 검증과 테스트에 사용할 계획이므로 변수 검토에 섞지 않는다.
    다만 2024년 4분기 행의 정답은 2025년 1분기의 실제값으로 만든다.

파생변수 만들기
    총매출만 보지 않고 점포당 매출, 주말 매출 비중, 프랜차이즈 비율처럼 의미를 나누어 본다.
    매출 8개와 점포 5개, 총 13개의 변수를 feat라는 별도 표에 만든다.


2절  꼭 알아둘 용어

데이터셋과 DataFrame
    데이터셋은 분석할 자료 묶음이다. DataFrame은 자료를 행과 열로 다루는 pandas의 표다.
    컬럼은 매출, 점포 수처럼 각각의 항목을 담는 열이다.

키
    다른 표에서 같은 대상을 찾기 위한 연결 기준이다. 여기서는 상권, 업종, 분기 코드다.

독립변수 X와 종속변수 y
    X는 판단에 사용할 정보, y는 맞혀야 할 정답이다.
    예를 들어 현재 매출과 점포 수가 X라면, 다음 분기 폐업위기 여부가 y다.

결측치와 NaN
    값이 없는 상태다. 폐업위기 정답이 없다고 0으로 바꾸면 안 된다.

유동인구, 상주인구, 배후지
    유동인구는 지역을 오가는 인구, 상주인구는 거주하는 인구다. 배후지는 상권 주변의 생활권이다.

파생변수
    기존 값을 계산해 만든 새 정보다. 점포당 매출은 총매출을 점포 수로 나눈 값이다.

상관계수
    두 값이 함께 움직이는 방향과 정도를 나타낸다. 범위는 -1부터 1이다.
    양수는 같은 방향, 음수는 반대 방향의 경향이다. 절댓값이 클수록 그 경향이 강하다.
    상관이 크다고 한쪽이 다른 쪽의 원인이라는 뜻은 아니다. 0에 가까울수록 두 변수 사이에 직선적인 관계X.

스피어만 상관
    실제 숫자의 크기 대신 순위를 비교한다. 이 노트북이 사용하는 상관분석 방식이다.
    0에 가까우면 이런 순위 관계가 약하다는 뜻이며, 모든 관계가 없다는 뜻은 아니다.

로그 변환과 표준편차
    로그 변환은 큰 값 사이의 차이를 압축한다. 표준편차는 값들이 얼마나 흩어져 있는지 나타낸다.
    여기서는 매출의 크기를 조절하고 요일별 매출 비중의 차이를 표현한다.

데이터 누수
    예측할 때 알 수 없는 미래 정보나 평가 자료가 학습과 변수 선택에 섞이는 것이다.
    다음 분기 폐업률을 입력에 넣으면 정답을 미리 보여주는 셈이다.

파라미터와 하이퍼파라미터
    모델의 파라미터는 데이터를 보고 학습하는 내부 값이다.
    하이퍼파라미터는 모델의 구조나 학습 방식을 정하는 설정값이다. 학습 반복 횟수가 한 예다.
    이 노트북은 자료 준비 단계이며 모델 학습과 하이퍼파라미터 조정은 아직 다루지 않는다.


3절  필수 함수만 기억하기

pd는 표를 다루는 pandas, np는 수치 계산에 쓰는 NumPy의 줄임 이름이다.

pd.read_csv() → CSV 자료를 표로 읽는다.

pd.concat() → 같은 형식의 연도별 자료를 아래로 이어 붙인다.

merge() → 공통 키가 일치하는 자료를 옆으로 붙인다. how='left'는 기준 표의 행을 남기는 방식이다.

groupby()와 shift(-1) → 같은 상권과 업종을 묶고, 정렬된 다음 행의 값을 현재 행으로 가져온다.

transform('sum') → 그룹의 합계를 구해 각 행에 붙인다. 업종 평균 폐업률을 만들 때 사용한다.

corr(method='spearman') → 변수와 정답의 순위 기반 상관계수를 계산한다.

np.log1p() → 1을 더한 값의 로그를 구한다. 0도 처리하면서 큰 매출값의 차이를 줄인다.


4절  현재 작성된 범위

dataset.csv에는 정답을 포함한 통합 자료를 저장하고, label_cols.csv에는 입력에서 제외할 컬럼을 적는다.
상관분석은 관계를 살펴보는 단계다. 상관이 낮다는 이유만으로 쓸모없는 변수라고 확정하지 않는다.
마지막의 feat는 생성까지 작성되어 있다. 통합 자료에 합치거나 저장하는 코드는 아직 없다.
