팀 프로젝트  조회와 추천 함수


1절  파일 역할

data.js → 공통 데이터
app.js → 조회와 추천과 비교 동작
maps.js → 선택 상권의 지도 표시
site.css → 화면 스타일 보정


2절  핵심 함수

current() → 현재 선택한 상권 가져오기
score() → 기본 점수 또는 변경 가중치의 점수 계산
ranked() → 조건에 맞는 상권을 점수순으로 정렬
fillMarketOptions() → 선택 자치구에 해당하는 상권 구성
applyFilters() → 조회 조건을 적용하고 화면 갱신
save() → 선택 상태를 localStorage에 저장
navigate() → 상태 저장 후 다른 페이지로 이동
localStorage → 브라우저에 값을 저장하는 공간


3절  처리 흐름

조회 조건 선택 → 상권 필터링 → 점수 계산 → 순위 정렬 → 화면 갱신
페이지를 이동할 때 선택 조건을 저장하고 주소에 반영한다.
