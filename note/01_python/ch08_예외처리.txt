예외처리


실행 중 발생한 오류를 처리하고 프로그램의 흐름을 관리한다.


1  처리 순서

try → 오류가 발생할 수 있는 작업을 실행한다.
except → 지정한 예외가 발생했을 때 처리한다.
else → try에서 예외 없이 작업을 마쳤을 때 실행한다.
finally → 예외 발생 여부와 관계없이 마무리 작업을 수행한다.
여러 except를 쓰면 구체적인 예외를 앞에 두고 상위 예외를 뒤에 둔다.


2  직접 발생시키기

raise → 필요할 때 예외를 직접 발생시킨다.


3  자원 관리

with → 파일 등 자원을 사용한 뒤 정리하도록 실행 범위를 관리한다.
