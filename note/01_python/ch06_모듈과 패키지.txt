모듈과 패키지


1  코드 가져오기

모듈 → 함수, 클래스, 변수 등을 담은 파일
패키지 → 관련 모듈을 묶은 구조
import → 모듈을 가져온다.
from → 가져올 함수, 클래스, 변수나 하위 모듈의 위치를 지정한다.
as → 가져온 대상에 다른 이름을 붙인다.
점으로 연결된 경로 → 패키지 안의 하위 모듈을 가리킨다.


2  패키지 관리

pip, conda, uv → 패키지 설치와 관리를 위한 도구
install → 설치, uninstall 또는 remove → 삭제
pip show, conda list → 설치된 패키지 정보 확인
버전 지정 → 필요한 패키지 버전을 정해 설치한다.
