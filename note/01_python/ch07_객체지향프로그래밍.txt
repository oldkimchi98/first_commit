객체지향 프로그래밍


1  클래스와 객체

class → 속성과 메서드를 가진 객체를 만드는 설계도
인스턴스 → 클래스를 바탕으로 만든 실제 객체
속성 → 객체의 데이터, 메서드 → 객체의 동작
모든 클래스는 기본적으로 object를 상속한다.
__init__() → 인스턴스의 초기 상태를 설정한다.
__del__() → 객체가 소멸할 때 호출된다.
__str__() → 객체를 문자열로 표현한다.


2  변수와 메서드

인스턴스 변수 → 객체마다 보유하는 값
클래스 변수 → 클래스에서 공유하는 값
인스턴스 메서드 → self로 현재 객체의 속성과 기능을 사용한다.
클래스 메서드 → cls로 클래스에 접근하며 classmethod로 지정한다.
정적 메서드 → 객체나 클래스를 자동으로 전달받지 않으며 staticmethod로 지정한다.
__dict__ → 객체에 저장된 속성을 딕셔너리로 확인한다.


3  상속

상속 → 부모 클래스의 속성과 기능을 자식 클래스에서 이어받아 사용한다.
super() → 상속 관계에서 부모 쪽의 메서드에 접근한다.
