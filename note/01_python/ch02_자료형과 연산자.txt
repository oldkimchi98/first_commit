자료형과 연산자


1  변수와 자료형

변수 → 값을 저장하는 이름이며 할당된 값에 따라 자료형이 정해진다. 이름에는 문자, 숫자, 밑줄을 쓰고 숫자로 시작하거나 예약어를 사용할 수 없다.
int → 정수, float → 실수, complex → 복소수
int(), float() → 숫자의 자료형을 변환한다.
bool → 참과 거짓을 나타낸다. 0, None, 비어 있는 문자열과 자료구조는 거짓으로 판단된다.


2  입력과 출력

input() → 사용자 입력을 문자열로 받는다.
print() → 값을 출력한다. sep은 값 사이 구분, end는 출력 끝을 지정한다.


3  연산자

산술 → +, -, *, /, //, **, %는 덧셈, 뺄셈, 곱셈, 나눗셈, 몫, 거듭제곱, 나머지다.
할당 → =는 값을 저장하고 +=, -= 등은 계산한 값을 다시 저장한다.
비교 → >, >=, <, <=, ==, !=로 크기와 같음 여부를 판단한다.
논리 → and는 모두 참, or는 하나 이상 참, not은 참과 거짓을 반대로 바꾼다.
비트 → &, |, ^, ~는 비트 단위 연산이다.


4  문자열

인덱싱 → 한 위치의 문자 선택, 슬라이싱 → 범위의 문자 추출
len() → 길이, replace() → 치환, find() → 위치 찾기
split() → 나누기, join() → 합치기, strip() → 양끝 공백 제거
upper(), lower() → 대소문자 변환
startswith(), endswith() → 시작과 끝 확인
format(), f 문자열 → 변수의 값을 넣고 정렬이나 자릿수를 지정한다.


5  날짜와 시간

datetime → 날짜와 시간, date → 날짜, time → 시간
datetime.now() → 현재 날짜와 시간을 가져온다.


6  정규표현식

정규표현식 → 문자 패턴으로 원하는 내용을 찾거나 바꾼다.
re.findall() → 모든 일치 항목, re.search() → 첫 일치 항목, re.sub() → 일치 내용 치환
\d → 숫자, \D → 숫자가 아닌 문자
\w → 문자와 숫자, 밑줄, \W → 그 외 문자, \s → 공백 문자
. → 줄바꿈을 제외한 임의의 문자, \. → 마침표 자체
? → 0회 또는 1회, + → 1회 이상, * → 0회 이상, {n,} → n회 이상
() → 패턴을 묶는다.
