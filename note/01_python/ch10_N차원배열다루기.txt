NumPy 배열의 함수와 속성


1  배열 확인

dtype → 자료형, itemsize → 요소 하나의 바이트 크기
ndim → 차원 수, size → 전체 요소 수, shape → 축별 크기
astype() → 요소의 자료형을 변환한다.


2  배열 생성

array() → 데이터로 배열 생성
arange() → 지정 간격으로 값 생성, linspace() → 지정 개수만큼 같은 간격으로 값 생성
균등분포 → 정한 범위에서 값이 고르게 나오는 분포
random(), uniform(), rand() → 균등분포 난수 생성
정규분포 → 평균을 중심으로 모이고 표준편차에 따라 퍼지는 분포
normal() → 정규분포 난수, randn() → 평균 0과 표준편차 1인 표준정규분포 난수


3  모양 변경

reshape() → 요소 수를 유지하며 모양 변경. 한 축에 -1을 쓰면 크기를 자동 계산한다.
resize() → 원본 배열의 크기 변경. -1로 자동 계산할 수 없다.
T, transpose() → 축의 순서 변경. 2차원에서는 행과 열을 바꾼다.
flatten(), ravel() → 1차원으로 펼치기
newaxis, expand_dims() → 축 추가


4  연산

요소별 연산 → 같은 위치의 값끼리 계산
@ → 행렬곱, 단위행렬 → 행렬곱에서 값을 그대로 유지하는 행렬
sum(), min(), max(), mean(), var(), std() → 합계, 최솟값, 최댓값, 평균, 분산, 표준편차
범용함수 → add(), sqrt()처럼 배열 요소에 연산을 적용하는 함수
브로드캐스팅 → 호환되는 배열의 모양을 맞춰 요소별 연산을 수행하는 규칙


5  합치기와 나누기

axis → 처리할 축
concatenate() → 기존 축을 따라 연결, stack() → 새 축을 만들어 쌓기
vstack(), hstack(), dstack() → 세로, 가로, 깊이 방향으로 쌓기
column_stack(), row_stack() → 열 또는 행 방향으로 쌓기
vsplit(), hsplit() → 행 또는 열 방향으로 분할
split() → 지정 축으로 같은 크기의 구간 분할
array_split() → 균등하게 나누어지지 않아도 분할
