제어문


1  조건문

if → 조건이 참일 때 실행한다.
elif → 앞 조건이 거짓이면 다음 조건을 확인한다.
else → 앞의 조건이 모두 거짓일 때 실행한다.
들여쓰기 → 같은 실행 범위에 속하는 문장을 구분한다.


2  반복문

for → 자료의 요소를 차례로 처리한다.
while → 조건이 참인 동안 반복한다.
break → 반복을 즉시 끝낸다.
continue → 현재 회차를 건너뛰고 다음 반복으로 간다.
반복문의 else → break 없이 반복을 정상적으로 마치면 실행한다.


3  중첩 반복

중첩 루프 → 반복문 안에 또 다른 반복문을 둔다.
break는 가장 안쪽 반복문만 끝낸다. 여러 단계에서 빠져나올 때는 종료 여부를 나타내는 flag 변수나 예외처리로 흐름을 제어한다.
