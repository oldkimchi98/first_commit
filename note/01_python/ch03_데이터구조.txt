데이터구조


여러 데이터를 한 변수에 담고 목적에 맞게 관리한다.


1  리스트

순서가 있고 요소를 수정할 수 있다. list()로 생성한다.
인덱싱 → 한 요소 선택, 슬라이싱 → 범위 추출
리스트 컴프리헨션 → 반복과 조건으로 필요한 요소를 모은다.
len(), min(), max(), sum() → 개수, 최솟값, 최댓값, 합계
sorted() → 정렬한 새 리스트, sort() → 원본 정렬
append() → 하나 추가, extend() → 여러 요소 추가, insert() → 지정 위치에 추가
index() → 위치, count() → 개수, in → 포함 여부
pop() → 꺼내며 삭제, remove() → 값으로 삭제, del → 지정 요소 삭제
copy() → 리스트를 얕게 복사한다. 내부 객체까지 새로 만드는 깊은 복사와 다르다.


2  튜플

순서가 있지만 요소를 수정할 수 없다. 요소가 하나일 때도 쉼표가 필요하다.


3  딕셔너리

키와 값을 짝으로 저장한다.
keys() → 키 목록, values() → 값 목록, items() → 키와 값의 쌍
get() → 키로 값을 조회한다. 없는 키를 조회해도 기본적으로 오류가 나지 않는다.
update() → 추가하거나 수정, pop() → 키로 삭제, in → 키 존재 여부
키 직접 조회나 삭제는 해당 키가 없으면 오류가 발생한다.


4  집합

중복을 허용하지 않으며 인덱스로 접근하지 않는다.
add() → 하나 추가, update() → 여러 요소 추가
remove() → 값 삭제. 없는 값을 삭제하면 오류가 발생한다.


5  순번과 값 함께 사용

enumerate() → 반복할 때 순번과 값을 함께 가져온다.
