함수


1  정의와 실행

함수 → 반복해서 쓸 작업을 하나로 묶는다. def로 정의하고 필요한 값을 매개변수로 받는다.
매개변수 → 함수가 받을 값의 이름, 인수 → 호출할 때 실제로 전달한 값
같은 이름으로 함수를 다시 정의하면 이전 정의를 덮어쓴다. 매개변수만 달리한 일반적인 오버로딩은 지원하지 않는다.
docstring → 함수의 목적과 사용법을 적는 설명


2  변수와 반환

지역변수 → 함수 안에서 사용하는 변수
전역변수 → 함수 밖에서 정의한 변수. 함수 안에서 재할당할 때는 global을 사용한다.
return → 실행을 끝내고 결과를 반환한다. 여러 값을 반환하면 튜플로 묶인다.


3  인수 전달

기본값 → 인수를 생략할 때 사용한다. 함수 정의 시 한 번 만들어지므로 변경 가능한 객체를 기본값으로 쓸 때 주의한다.
위치 인수 → 순서대로 전달, 키워드 인수 → 매개변수 이름으로 전달
*args → 여러 위치 인수를 튜플로 받는다.
**kwargs → 여러 키워드 인수를 딕셔너리로 받는다.
언패킹 → 호출할 때 *로 요소를 위치 인수로, **로 키와 값을 키워드 인수로 풀어 전달한다.
기본 정의 순서 → 일반 매개변수 → 가변 위치 인수 → 키워드 전용 매개변수 → 가변 키워드 인수


4  람다식

lambda → 간단한 식으로 이름 없는 함수를 만든다.
