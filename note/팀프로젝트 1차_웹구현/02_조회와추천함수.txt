팀 프로젝트 - 조회와 추천 함수

1절. 파일 역할
data.js : 공통 샘플 데이터
app.js : 조회·추천·비교 등 화면 동작
maps.js : 선택 상권의 지도 그림 표시
site.css : 추가 기능과 화면 보정 스타일

2절. 작성한 함수
$(), $$() : 화면 요소 하나 또는 여러 개 찾기
find() : 상권 ID에 맞는 데이터 찾기
current() : 현재 선택한 상권 가져오기
fmt() : 숫자에 쉼표를 붙이고 없는 값 안내
escape() : HTML에 넣을 문자열의 특수문자 변환
weightsChanged() : 기본 가중치에서 변경됐는지 확인
score() : 기본 점수 또는 변경 가중치의 점수 계산
ranked() : 조건에 맞는 상권을 점수순으로 정렬
populateSelects() : 조회 선택창 구성
fillMarketOptions() : 자치구에 해당하는 상권 구성
applyFilters() : 조회 조건을 적용하고 화면 갱신

3절. 상태와 이동
save() : 선택 상태를 localStorage에 저장
url() : 선택 조건이 포함된 주소 생성
navigate() : 상태 저장 후 다른 페이지로 이동
updateURL() : 현재 주소와 선택 상태 갱신
wireLinks() : 메뉴·링크에 선택 조건 반영

cf. $, $$는 이 프로젝트에서 만든 함수. jQuery가 아님.
직접 만든 find()와 배열의 find()는 구분해서 읽기.
