팀 프로젝트 - 사용한 태그와 속성

1절. 화면 구조
header : 사이트 이름과 상단 메뉴
nav : 주요 메뉴와 화면 이동 링크
aside : 왼쪽 조회 조건과 지도 영역
main : 페이지의 핵심 내용
section : 위험 요약, 차트, 추천 기준 구역
article : 개별 상권 카드
div, span : 디자인 적용을 위한 내용 묶음

2절. 조회 및 비교
form : 조회 조건 묶음
label : 입력 요소의 이름 (for와 id 연결)
select, option : 자치구·상권·업종·분기 선택
input type="range" : 추천 가중치 조절
input type="checkbox" : 비교할 상권 선택
button : 조회, 초기화, 비교, 상세 보기
table, thead, tbody, tr, th, td : 상권 비교표
scope : 표 머리글의 행·열 범위 지정

3절. 추가 내용
figure, figcaption : 지도와 설명 묶음
details, summary : 추가 설명 펼침·접기
dialog : 근거 지표와 점수 구성 팝업
svg : 분기별 매출 그래프

4절. 연결 속성
class, id : 스타일 적용 및 요소 찾기
data-action : 실행할 동작 이름
data-nav : 이동할 페이지
data-market : 상권 ID
aria-label : 버튼·지도 등의 접근 가능한 이름
hidden : 현재 사용하지 않는 영역 숨김

cf. 지도는 첨부 이미지의 일부를 배경으로 표시.
실제 모델 결과가 없는 항목은 준비 상태로 표시.
