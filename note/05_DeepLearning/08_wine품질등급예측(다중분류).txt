8장  레드 와인 품질 등급의 다중분류


핵심 이해

목표 → 와인의 특성을 입력받아 품질 등급을 여러 클래스 중 하나로 분류한다.
입력 X → 와인의 측정 특성. 타겟 y → 품질 등급. 출력층의 개수는 분류하려는 클래스 수에 맞춘다.
흐름 → 결측치와 클래스 비율 확인 → 입력과 타겟 분리 → 데이터 분할 → 입력 표준화와 타겟 인코딩 → 모델 학습 → 평가 → 등급 예측.


전처리와 모델

StandardScaler → 평균과 표준편차를 기준으로 변수의 스케일을 맞춘다. 새 입력에도 학습한 변환 기준을 그대로 적용한다.
원핫 인코딩 → 품질 등급별 열을 만들고 해당 등급의 열만 1로 표시한다. 학습셋과 시험셋의 클래스 순서는 같아야 한다.
stratify → 데이터 분할 때 클래스 비율을 유지하는 설정. 특정 등급에 데이터가 몰려 있으면 전체 정확도와 클래스별 오류를 함께 본다.
은닉층 relu → 특징을 학습하는 활성화 함수. 출력층 softmax → 클래스별 확률을 만들며 합은 1이다.
categorical_crossentropy → 원핫 타겟의 분류 손실. He 초기화 → relu 계열 층에서 가중치의 초기 크기를 조정해 학습을 돕는다.


학습과 평가

Dropout → 학습 중 일부 뉴런을 꺼 과적합을 줄인다. EarlyStopping → 검증 성능이 개선되지 않으면 학습을 종료한다.
정확도 → 전체에서 맞힌 비율. 재현율 → 실제 해당 클래스 중 찾아낸 비율. 정밀도 → 해당 클래스 예측 중 맞힌 비율.
등급 복원 → argmax 결과는 출력 열의 위치다. 원핫 인코딩에 사용한 클래스 목록과 연결해 실제 품질 등급을 찾는다.
시험셋 평가와 실제 등급·예측 등급의 교차표로 오류를 확인한다. 새 입력은 같은 스케일 변환을 거친 뒤 예측한다.


필수 함수

StandardScaler() → 입력 표준화. pd.get_dummies() → 원핫 인코딩. train_test_split() → 데이터 분할.
compile()과 fit() → 학습 설정과 실행. evaluate() → 시험셋 평가.
predict() → 클래스 확률 예측. argmax() → 가장 큰 확률의 출력 열 위치. pd.crosstab() → 실제 등급과 예측 등급 비교.
