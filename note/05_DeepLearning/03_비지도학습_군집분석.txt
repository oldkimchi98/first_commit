3장  비지도학습과 군집 분석


핵심 이해

비지도학습 → 정답 라벨 없이 데이터의 관계와 구조를 찾는 학습.
군집화 → 특징이 비슷한 데이터끼리 묶는 작업. 분류가 미리 정해진 정답을 학습한다면, 군집화는 데이터 안에서 그룹을 발견한다.
KMeans → 각 데이터를 가까운 중심점에 배정하고, 그룹의 평균 위치로 중심점을 옮기는 과정을 반복한다.


전체 흐름

숫자형 특징 준비 → 스케일 조정 → 군집 수 결정 → 초기 중심점 설정 → 가장 가까운 중심점에 데이터 배정 → 그룹 평균으로 중심점 갱신 → 배정과 갱신 반복.
반복이 진행되면서 군집 내부 데이터와 중심점 사이의 제곱거리 합을 줄인다. 중심점이나 배정 결과가 거의 바뀌지 않으면 수렴한 것으로 본다.


기억할 개념

거리 → 두 데이터가 얼마나 떨어져 있는지 나타낸다. 유클리드 거리는 좌표 차이의 제곱을 합한 뒤 제곱근을 구한 값이다.
중심점 → 한 군집에 속한 데이터들의 특징별 평균 위치. 실제 데이터 중 하나일 필요는 없다.
스케일 → 변수의 숫자 범위. 범위가 큰 변수가 거리 계산을 좌우할 수 있으므로 변수들의 단위를 맞춘다.
n_clusters → 찾을 군집 수. init → 처음 중심점을 정하는 방법. n_init → 초기 중심점을 바꿔 여러 번 학습하는 횟수.
군집 번호 → 그룹을 구별하는 번호이며, 원래 범주의 이름이나 순서를 뜻하지 않는다.
하이퍼파라미터 → 군집 수처럼 학습 전에 사람이 정하는 설정. 학습 결과로 얻는 중심점과 구분한다.


필수 함수와 결과

KMeans() → 군집 모델 생성. fit() → 군집 중심 학습. predict() → 새 데이터의 군집 배정.
cluster_centers_ → 학습한 중심점. labels_ → 학습 데이터에 배정된 군집 번호.
전처리의 fit()은 변환 기준을 학습하고, transform()은 그 기준으로 데이터를 바꾼다.
