7장  MNIST 손글씨 분류와 콜백 함수


핵심 이해와 흐름

MNIST → 손글씨 숫자를 10개 클래스로 분류하는 이미지 데이터. 한 이미지는 28행 28열이며, Dense 모델에서는 784개 입력으로 펼친다.
흐름 → 데이터 분리 → 픽셀 실수 변환과 스케일 조정 → 타겟 원핫 인코딩 → 모델 학습 → 검증 성능으로 조정 → 시험셋 평가.
출력 → softmax로 각 숫자의 확률을 구하고 argmax로 가장 큰 확률의 숫자를 선택한다. 원핫 타겟에는 categorical_crossentropy를 사용한다.


성능을 높이는 관점

데이터의 양과 품질, 층과 뉴런 수, 활성화 함수, optimizer와 학습률을 검토한다. 모델이 커진다고 성능이 항상 좋아지지는 않는다.
Dropout → 일부 뉴런을 꺼 과적합을 줄인다. BatchNormalization → 층의 계산을 안정화한다. L2 규제 → 지나치게 큰 가중치를 억제한다.
LeakyReLU → 음수 입력도 작은 비율로 통과시키는 활성화 함수.
학습 지표와 검증 지표를 함께 비교한다. 시험셋은 최종 평가에 사용하고, 혼동행렬로 어떤 숫자를 자주 혼동하는지 살핀다.


꼭 기억할 콜백

콜백 → 학습 중 정해진 시점에 자동으로 실행되는 동작. fit()의 callbacks에 전달한다.
EarlyStopping → 관찰하는 지표가 일정 기간 개선되지 않으면 학습을 종료한다.
ModelCheckpoint → 학습 중 모델을 저장한다. save_best_only를 사용하면 관찰 지표가 개선된 모델만 저장한다.
ReduceLROnPlateau → 성능 개선이 정체되면 학습률을 낮춘다.
monitor → 관찰할 지표. patience → 개선 없이 기다릴 기간. val_loss는 작을수록, val_accuracy는 클수록 좋다.
on_epoch_end() → 한 에포크가 끝날 때 실행되는 사용자 콜백의 동작 지점. 에포크는 학습 데이터 전체를 한 번 학습하는 단위다.


필수 함수

mnist.load_data() → 데이터 불러오기. reshape() → 이미지 펼치기. to_categorical() → 타겟 인코딩.
fit(), evaluate(), predict() → 학습·평가·예측. argmax()와 confusion_matrix() → 클래스 선택과 오류 확인.
