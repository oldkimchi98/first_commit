전처리 실습  라벨 인코딩과 스케일 조정, 원핫 인코딩


핵심 이해와 흐름

전처리 → 모델이 학습할 수 있도록 데이터의 표현과 숫자 크기를 정리하는 작업.
흐름 → 입력 X와 타겟 y 분리 → 범주 인코딩 → 학습·검증·시험 데이터 분리 → 학습 데이터로 변환 기준 결정 → 다른 데이터에 같은 기준 적용.
입력변수 → 예측에 사용할 근거. 타겟변수 → 맞혀야 하는 결과. 수치형 타겟을 예측하면 회귀 문제다.


범주를 숫자로 표현하기

라벨 인코딩 → 범주마다 정수 번호를 부여한다. LabelEncoder는 타겟 라벨 변환에 사용한다. 범주의 번호가 크기나 순서를 뜻하지는 않는다.
원핫 인코딩 → 범주별 열을 만들고 해당 열만 1, 나머지는 0으로 표시한다. 순서가 없는 입력 범주를 숫자의 대소 관계 없이 표현할 수 있다.
인코딩 후에도 어떤 번호나 열이 어떤 범주를 뜻하는지 변환 규칙을 유지해야 한다.


숫자 크기를 맞추기

MinMaxScaler → 최솟값과 최댓값을 기준으로 범위를 맞춘다. 기본 범위는 0부터 1이다.
StandardScaler → 평균과 표준편차를 기준으로 표준화한다. 학습 데이터에서 평균은 0, 표준편차는 1에 맞춘다.
변수마다 숫자 크기가 다르면 특정 변수가 학습에 과하게 영향을 줄 수 있다. 스케일 조정은 이 차이를 줄이는 과정이다.
입력과 타겟은 별도 변환 기준을 사용한다. 타겟의 스케일도 바꿨다면 예측 후 원래 단위로 복구한다.


필수 함수

LabelEncoder() → 라벨 인코딩. pd.get_dummies() → 원핫 인코딩. MinMaxScaler()와 StandardScaler() → 스케일 조정.
fit() → 변환 기준 학습. transform() → 학습한 기준으로 변환. fit_transform() → 두 과정을 함께 수행.
inverse_transform() → 변환 전 값으로 복구. to_numpy() → 데이터프레임을 배열로 변환.
기억할 기준 → 학습 데이터에는 fit과 transform, 검증·시험·새 입력에는 같은 변환기의 transform을 사용한다.
