시계열 분석  Statsmodels와 Prophet


핵심 이해

시계열 → 시간 순서에 따라 기록된 데이터. 과거의 흐름을 분석하고 앞으로의 값을 예측한다.
Statsmodels → 통계분석 라이브러리. seasonal_decompose로 시계열을 여러 요소로 나누어 흐름을 살핀다.
Prophet → 추세, 계절성, 휴일 효과 등을 모델링하는 시계열 예측 도구. 분해는 흐름의 이해에, 예측 모델은 미래값 추정에 사용한다.


전체 흐름

날짜형으로 변환 → 분석 대상을 선택 → 결측치와 시간 간격 확인 → 날짜를 기준으로 정렬 → 추세와 계절성 분석 → 모델 학습 → 미래 날짜 생성 → 예측.
시간 순서는 데이터의 일부다. 미래 예측을 평가할 때도 과거 데이터로 학습하고 이후 데이터와 비교한다.


시계열을 이루는 요소

observed → 실제 관측값. trend → 장기적인 증가나 감소 흐름.
seasonal → 일정한 주기로 반복되는 패턴. resid → 추세와 계절성으로 설명되지 않는 잔차.
additive → 실제값을 추세, 계절성, 잔차의 합으로 설명하는 방식. period → 반복 패턴 한 주기의 관측 수.


Prophet의 데이터와 결과

ds → 날짜 열. y → 예측할 실제값 열. 이 이름으로 입력 데이터를 준비한다.
yhat → 예측값. yhat_lower와 yhat_upper → 예측의 불확실성 범위를 나타내는 하한과 상한.
추세와 계절성 구성 요소를 함께 보면 예상 변화의 근거를 살필 수 있다. 예측값과 불확실성 범위를 함께 읽는다.


필수 함수

pd.to_datetime()과 set_index() → 날짜 변환과 시계열 인덱스 설정.
seasonal_decompose() → 관측값을 추세·계절성·잔차로 분해.
Prophet()과 fit() → 예측 모델 생성과 학습. make_future_dataframe() → 미래 날짜 생성.
predict() → 날짜별 값 예측. plot_components() → 예측을 이루는 요소 확인.
