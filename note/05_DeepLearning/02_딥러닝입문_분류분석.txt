2장  딥러닝 입문과 분류 분석


핵심 이해

딥러닝 → 여러 층의 신경망으로 데이터의 특징과 관계를 학습한다. 분류는 범주를 고르고, 회귀는 연속적인 수치를 예측한다.
지도학습 → 입력과 정답으로 학습. 비지도학습 → 정답 없이 데이터의 구조를 찾음. 강화학습 → 행동에 따른 보상을 바탕으로 학습.


전체 흐름

데이터 확보 → 결측치 처리와 인코딩 → 학습·검증·시험 데이터 분리 → 학습 데이터 기준으로 스케일 조정 → 모델 구성과 학습 → 평가 → 예측.
학습셋 → 가중치 학습에 사용. 검증셋 → 학습 중 성능과 설정 점검에 사용. 시험셋 → 최종 성능 확인에 사용.


기억할 개념

라벨 인코딩 → 범주에 정수 번호를 붙인다. 번호 자체가 크기나 순서를 의미하지는 않는다.
원핫 인코딩 → 범주별 열을 만들고 해당 열만 1, 나머지는 0으로 표현한다. 입력과 타겟의 형태가 모델 구조에 맞아야 한다.
은닉층 → 입력의 특징을 계산하는 중간 층. 활성화 함수 → 층의 계산 결과를 변환해 복잡한 관계를 학습하게 한다.
sigmoid → 하나의 출력으로 이진 확률을 표현. softmax → 여러 클래스의 확률을 표현하며 합은 1이다.
손실함수 → 이진분류는 binary_crossentropy, 원핫 타겟의 다중분류는 categorical_crossentropy를 사용한다.
정확도 → 전체에서 맞힌 비율. 재현율 → 실제 양성 중 찾아낸 비율. 정밀도 → 양성 예측 중 실제 양성 비율.
과적합 → 학습 데이터에는 잘 맞지만 새 데이터의 성능은 떨어지는 상태. 학습 지표와 검증 지표를 함께 비교한다.


필수 함수

LabelEncoder() → 라벨 인코딩. to_categorical() 또는 pd.get_dummies() → 원핫 인코딩.
Sequential()과 Dense() → 모델 구성. compile() → 학습 설정. fit() → 학습.
evaluate() → 시험셋 평가. predict() → 분류 확률 예측. argmax() → 가장 큰 확률의 출력 열 위치. 이 위치를 실제 범주와 연결한다.
