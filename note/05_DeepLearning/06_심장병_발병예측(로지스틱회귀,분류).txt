6장  심장병 발병 예측과 과적합 조정


핵심 이해와 흐름

목표 → 심장병 발병 여부를 분류하며 결측치, 클래스 불균형, 과적합을 함께 다룬다.
흐름 → 결측 표시를 실제 결측값으로 변환 → 결측치 처리 → 입력과 타겟 분리 → 학습·검증·시험셋 분리 → 입력 스케일 조정 → 모델 학습 → 평가와 예측.
새 입력에도 학습 때 정한 스케일 변환을 적용한다. stratify는 데이터 분할 때 타겟의 클래스 비율을 유지하는 설정이다.


출력과 평가

sigmoid 출력 하나 → 이진 라벨과 binary_crossentropy 사용. softmax 출력 두 개 → 원핫 타겟과 categorical_crossentropy 사용.
정확도 → 전체 정답 비율. 재현율 → 실제 양성 중 찾아낸 비율. 정밀도 → 양성 예측 중 실제 양성의 비율.
임계값 → 양성과 음성을 가르는 확률 기준. 기준을 바꾸면 재현율과 정밀도의 균형도 달라진다. 혼동행렬로 놓친 양성과 잘못 판단한 양성을 확인한다.


과적합과 불균형 조정

과적합 → 학습 데이터에만 지나치게 맞춰 새 데이터의 성능이 떨어지는 상태. 학습 손실과 검증 손실을 함께 본다.
Dropout → 학습 중 일부 뉴런을 무작위로 꺼 특정 연결에 과하게 의존하지 않게 한다.
BatchNormalization → 층의 출력을 배치 단위로 정규화해 학습을 안정화한다.
L2 규제 → 큰 가중치에 부담을 더해 지나치게 복잡한 학습을 줄인다.
클래스 가중치 → 적은 클래스의 오분류가 손실에 더 크게 반영되도록 한다. 원래 데이터 개수를 바꾸는 방법은 아니다.
ReduceLROnPlateau → 검증 성능 개선이 멈추면 학습률을 낮춰 더 세밀하게 학습한다.


필수 함수

replace()와 dropna() → 결측 표시 변환과 결측 행 처리. train_test_split() → 데이터 분할.
MinMaxScaler() → 입력 스케일 조정. compute_class_weight() → 클래스별 학습 가중치 계산.
Dropout(), BatchNormalization(), l2() → 학습 구조 조정. fit(), evaluate(), predict() → 학습·평가·예측.
confusion_matrix() → 실제 분류와 예측 비교.
