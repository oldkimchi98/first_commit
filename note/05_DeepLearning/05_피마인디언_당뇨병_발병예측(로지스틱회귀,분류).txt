5장  피마 인디언 당뇨병 발병 예측


핵심 이해

목표 → 건강 관련 입력변수로 당뇨병 발병 여부를 분류한다. 같은 이진 문제를 sigmoid 출력 하나 또는 softmax 출력 두 개로 표현할 수 있다.
입력 → 임신횟수, 포도당 농도, 혈압, 피부접힘 두께, 인슐린, BMI, 가족력 관련 지표, 나이. 타겟 → 발병 여부.


전체 흐름

데이터 구조와 결측치 확인 → 입력과 타겟 분리 → 타겟 비율 확인 → 학습·검증·시험셋 분리 → 모델 구성과 학습 → 평가 → 예측.
학습셋 → 모델 학습. 검증셋 → 학습 중 성능 점검. 시험셋 → 마지막 성능 평가. 학습셋 성능만으로 모델의 예측력을 판단하지 않는다.


두 가지 출력 방식

sigmoid → 양성일 확률 하나를 출력한다. 타겟은 이진 라벨, 손실함수는 binary_crossentropy를 쓴다. 정한 임계값을 기준으로 양성과 음성을 결정한다.
softmax → 음성과 양성의 확률을 각각 출력한다. 타겟을 원핫 인코딩하고 categorical_crossentropy로 학습한다. 가장 큰 확률의 클래스를 선택한다.
임계값 → 확률을 최종 분류로 바꾸는 기준. 확률 자체와 분류 결과를 구분해야 한다.


평가에서 볼 것

혼동행렬 → 실제값과 예측값을 비교한 표. TP는 양성을 맞힘, TN은 음성을 맞힘, FP는 음성을 양성으로 잘못 판단, FN은 양성을 놓침.
정확도 → 전체에서 맞힌 비율. 정밀도 → 양성 예측 중 실제 양성의 비율. 재현율 → 실제 양성 중 찾아낸 비율.
과적합 → 학습 성능은 좋아지지만 검증 성능은 나빠지는 상태. 손실과 정확도를 학습·검증 데이터에서 함께 확인한다.


필수 함수

to_categorical() → 타겟 원핫 인코딩. compile() → 출력 방식에 맞는 손실 설정. fit() → 학습.
evaluate() → 시험셋 평가. predict() → 분류 확률 예측. argmax() → softmax 출력에서 가장 큰 확률의 클래스 위치.
confusion_matrix() → 분류 결과 비교.
