1장  머신러닝 입문과 선형 회귀


핵심 이해

머신러닝 → 입력과 정답의 관계를 데이터에서 학습한다. 사람이 계산 규칙을 직접 정하는 방식과 달리, 학습한 관계로 새로운 입력의 결과를 예측한다.
선형 회귀 → 입력이 변할 때 연속적인 수치가 어떻게 달라지는지 직선 관계로 추정한다. 가중치는 입력의 영향력, 편향은 예측값의 기본 위치를 뜻한다.


전체 흐름

데이터 준비 → 입력과 타겟 분리 → 데이터 분할 → 학습 데이터 기준으로 스케일 조정 → 모델 구성 → 학습 설정 → 학습 → 시험 데이터 평가 → 새로운 값 예측.
입력변수 X → 예측의 근거가 되는 값. 타겟변수 y → 모델이 맞혀야 하는 정답.
스케일 조정 → 변수마다 다른 숫자 크기를 맞춰 학습을 안정화한다. 새 입력에도 학습 때 사용한 변환 기준을 적용한다.


기억할 개념

Dense → 이전 층의 모든 입력을 연결해 계산하는 층. 수치 하나를 예측하는 회귀 모델은 출력도 하나다.
loss → 학습 중 줄여야 하는 오차. optimizer → 오차가 줄어드는 방향으로 가중치와 편향을 바꾸는 도구. metrics → 성능을 확인하는 지표.
MSE → 오차 제곱의 평균으로 큰 오차에 민감하다. RMSE → MSE의 제곱근으로 타겟과 같은 단위를 쓴다. MAE → 오차 절댓값의 평균.
노이즈 → 실제 관계에 섞인 불규칙한 변동. 모든 점을 그대로 외우기보다 전체 경향을 학습하는 것이 중요하다.


필수 함수

Sequential()과 Dense() → 모델과 층 구성. compile() → 손실함수와 학습 방법 설정.
fit() → 데이터로 학습. evaluate() → 성능 평가. predict() → 새로운 입력의 결과 예측.
save()와 load_model() → 학습한 모델 저장과 불러오기.
