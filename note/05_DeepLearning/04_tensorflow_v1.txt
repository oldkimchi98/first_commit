4장  TensorFlow v1과 회귀분석


핵심 이해

TensorFlow v1 → 연산 그래프를 먼저 만들고 세션에서 실행하는 방식.
텐서 → 숫자를 담는 다차원 배열. 그래프의 노드는 데이터와 연산을 나타내며, 연결은 데이터가 흐르는 관계를 나타낸다.
실행 흐름 → 그래프 정의 → Session 생성 → 변수 초기화 → run으로 학습과 예측 실행.


그래프의 구성

constant → 변하지 않는 값. Variable → 가중치와 편향처럼 학습 중 바뀌는 값.
placeholder → 실행할 때 데이터를 넣는 입력 자리. feed_dict → 입력 자리와 실제 데이터를 연결하는 전달 방식.
shape → 배열의 차원과 크기. None → 데이터의 행 수를 고정하지 않는다는 뜻. 특징 수와 가중치의 행렬 크기는 서로 맞아야 한다.


회귀와 스케일 조정

회귀 → 입력의 가중합에 편향을 더해 수치를 예측한다. 입력이 하나면 직선 관계, 여러 개면 행렬곱으로 표현한다.
손실 MSE → 예측값과 정답 차이의 제곱 평균. 경사하강법 → 손실이 줄어드는 방향으로 가중치와 편향을 갱신한다.
학습률 → 한 번에 얼마나 크게 갱신할지 정하는 값. 너무 크면 학습이 불안정해질 수 있다.
MinMaxScaler → 최솟값과 최댓값으로 숫자 범위를 맞추는 정규화. StandardScaler → 평균과 표준편차를 기준으로 맞추는 표준화.
예측 흐름 → 학습한 기준으로 입력 변환 → 그래프 실행 → 타겟도 스케일을 바꿨다면 원래 단위로 복구.


필수 함수

tf.Session()과 sess.run() → 실행 환경 생성과 연산 실행. tf.global_variables_initializer() → 변수 초기화.
tf.Variable()과 tf.placeholder() → 학습 변수와 입력 자리 생성. tf.matmul() → 행렬곱.
tf.reduce_mean()과 tf.square() → MSE 계산. GradientDescentOptimizer().minimize() → 손실을 줄이는 학습 연산 생성.
fit_transform() → 스케일 기준 학습과 변환. transform() → 같은 기준 적용. inverse_transform() → 원래 단위 복구.
