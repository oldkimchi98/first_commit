4장  관계와 상태 선택자


1절  요소 관계

후손 선택자 → 공백으로 연결하며 안쪽의 모든 단계 선택
자식 선택자 → >로 연결하며 바로 아래 요소 선택
인접 형제 선택자 → +로 연결하며 바로 다음 형제 선택
일반 형제 선택자 → ~로 연결하며 뒤에 오는 형제들 선택


2절  반응과 상태

:hover → 마우스를 올린 상태
:focus → 초점이 있는 상태
:enabled와 :disabled → 활성화와 비활성화 상태
:read-only → 사용자가 수정할 수 없는 상태


3절  구조와 문자

:first-child와 :last-child → 첫 번째와 마지막 자식
:nth-child() → 같은 부모의 전체 형제 순서로 선택
:not() → 지정한 조건에 맞지 않는 요소
::first-letter와 ::first-line → 첫 글자와 첫 줄
::selection → 사용자가 선택한 부분
