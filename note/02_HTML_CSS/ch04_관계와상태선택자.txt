4장. 관계·상태 선택자

1절. 요소 관계
div p : div 안의 모든 단계 p (후손)
div > p : div의 바로 아래 p (자식)
h3 + div : h3 바로 다음의 div 형제
h3 ~ div : h3 다음의 div 형제들

2절. 반응과 상태
:hover : 마우스를 올린 상태
:focus : 초점이 있는 상태
:enabled : 활성화된 입력 요소
:disabled : 비활성화된 입력 요소
:read-only : 사용자가 수정할 수 없는 상태

3절. 구조
:first-child : 첫 번째 자식
:last-child : 마지막 자식
:nth-child(2n) : 짝수 번째 자식
:nth-child(2n+1) : 홀수 번째 자식
:not(.web) : .web 조건에 맞지 않는 요소

4절. 문자
::first-letter : 첫 글자
::first-line : 첫 줄
::selection : 사용자가 선택한 부분

cf. nth-child는 같은 부모의 전체 요소 형제 순서 기준.
focus 표시를 제거한다면 다른 식별 가능한 표시 제공.
