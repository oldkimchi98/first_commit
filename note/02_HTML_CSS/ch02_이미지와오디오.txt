2장  이미지와 오디오


1절  이미지

img → 이미지 삽입
src → 이미지 파일 경로
alt → 이미지의 의미를 대신하는 설명
width와 height → 너비와 높이
원본 비율과 다르게 크기를 지정하면 이미지가 변형된다.


2절  오디오

audio → 오디오 삽입
source → 미디어 파일과 형식 지정
controls → 재생 도구 표시
loop → 반복 재생
autoplay → 자동 재생 요청
preload → 미리 불러올 데이터 범위에 관한 힌트
none은 미리 불러오지 않음, metadata는 정보 위주, auto는 전체 데이터 로딩을 허용한다.
파일 경로와 확장자를 확인한다. 자동 재생은 브라우저에서 제한될 수 있다.
