3장  입력 양식


1절  양식 구조

form → 사용자 입력을 제출하는 양식
input → 입력창과 선택 요소
label → 입력 요소의 이름. for와 id로 연결
select와 option → 선택 목록과 항목
textarea → 여러 줄 입력
fieldset과 legend → 입력 요소 묶음과 제목


2절  input의 type

text와 password → 한 줄 입력과 문자를 가리는 입력
tel과 email → 전화번호와 이메일
number와 date → 숫자와 날짜
file → 파일 선택
radio → 같은 name 그룹에서 하나 선택
checkbox → 항목별 선택
hidden → 화면에 표시하지 않는 제출값
submit과 reset → 제출과 초기값 복원
button → 일반 버튼


3절  제출 속성

action → 제출 주소
method → GET 또는 POST
name과 value → 제출 항목의 이름과 값
checked와 selected → 기본 선택
GET은 값이 URL에 포함될 수 있다. POST와 password 자체가 데이터를 암호화하지는 않는다.
