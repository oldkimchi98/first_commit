4장  CSS 기본 선택자


1절  역할

선택자 → 스타일을 적용할 요소 선택
속성 → 바꿀 디자인 항목
값 → 속성에 적용할 설정


2절  선택 방법

태그 선택자 → 같은 태그의 요소 선택
#id → 해당 id의 요소 선택. 문서 안에서 고유하게 사용
.class → 해당 class의 요소 선택. 여러 요소에 반복 사용
* → 모든 요소 선택
쉼표 → 여러 선택자를 함께 지정


3절  속성 선택자

[속성] → 속성이 있는 요소
[속성=값] → 속성값이 일치하는 요소
^= → 지정한 값으로 시작
$= → 지정한 값으로 끝남
*= → 지정한 값이 포함됨
선택자 사이의 공백과 쉼표는 의미가 다르다.
