4장. CSS 기본 선택자

1절. 기본 문법
선택자 { 속성: 값; }
선택자 : 스타일을 적용할 요소 선택

2절. 선택 방법
* : 모든 요소
p : p 태그
#header : id가 header인 요소
.menu : class가 menu인 요소
div#header : id가 header인 div
li.odd : class에 odd가 있는 li
h1, p : h1과 p를 각각 선택

3절. 속성 선택자
input[type="password"] : type 값이 password
img[alt] : alt 속성이 있는 이미지
[title^="남자"] : 값이 남자로 시작
[href$=".pdf"] : 값이 .pdf로 끝남
[class*="menu"] : 값에 menu가 포함

예)
.menu { color: green; }
input[type="password"] { border: 1px solid gray; }

cf. id는 문서 안에서 고유하게 사용.
class는 여러 요소에 반복 사용 가능.
선택자 사이 공백과 쉼표는 의미가 다름.
