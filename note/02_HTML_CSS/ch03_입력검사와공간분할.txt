3장  입력 검사와 공간 분할


1절  입력 검사

required → 필수 입력
placeholder → 짧은 입력 힌트
pattern → 입력값이 맞아야 하는 정규식
min과 max → 최소값과 최대값
readonly → 사용자 수정 방지
disabled → 비활성화하며 일반적으로 제출에서도 제외
입력창의 이름은 label로 표시한다. 브라우저 검사와 서버 검사는 각각 필요하다.


2절  JavaScript 검사

value → 입력값
trim() → 앞뒤 공백 제거
length → 문자열 길이
focus() → 입력창으로 초점 이동


3절  공간 분할

div → 영역 묶음
span → 문장 일부 묶음
header → 머리말
nav → 주요 메뉴
section → 주제별 내용
footer → 하단 정보
