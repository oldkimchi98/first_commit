2장  목록과 표 태그


1절  목록

ul → 순서가 없는 목록
ol → 순서가 있는 목록
li → 목록의 개별 항목
ol의 start와 type → 시작 번호와 번호 형식


2절  표 구조

table → 표
caption → 표 제목과 설명
tr → 행
th → 머리글 셀
td → 일반 셀
thead와 tbody → 머리글 행과 본문 행 묶음


3절  셀 병합

colspan → 가로로 합칠 열의 개수
rowspan → 세로로 합칠 행의 개수
병합한 자리에는 셀을 중복 작성하지 않는다.
표는 데이터 표시에 사용한다. 테두리와 셀 간격은 CSS의 border와 border-spacing으로 조절한다.
