5장  표시와 위치


1절  표시 방식

display → 요소의 배치 방식
block → 블록 형태
inline → 문장 안의 형태
inline-block → 가로 배치하면서 너비와 높이 지정
none → 표시와 배치 공간 모두 제거
visibility의 hidden → 숨기되 공간 유지
opacity → 투명도


2절  위치

position → 배치 기준
static → 기본 배치
relative → 원래 위치에서 이동하며 기존 공간 유지
absolute → 일반 배치에서 빠져 기준 영역에 배치
fixed → 보통 화면을 기준으로 고정
top과 right와 bottom과 left → 기준점과의 거리
z-index → 같은 쌓임 맥락 안의 겹침 순서
absolute는 보통 position이 지정된 가까운 조상이 기준이다.


3절  내용 흐름

float → 요소를 띄우고 주변 내용이 흐르게 배치
clear → 앞의 float 아래로 배치
overflow → 넘친 내용의 처리 방식
