2장. 글자와 링크 태그

1절. 글자
h1~h6 : 제목 단계 (h7은 표준 제목 태그가 아님)
p : 문단 생성
br : 줄바꿈
hr : 주제 전환·내용 구분
strong : 중요한 내용 표시
b : 중요성 추가 없이 주의를 끌 내용 표시
i : 용어 등 일반 문장과 구별되는 내용 표시
sup : 위 첨자
sub : 아래 첨자
ins : 추가된 내용
del : 삭제된 내용
span : 문장 일부를 묶어 스타일 적용

2절. 링크
a : 다른 페이지 또는 문서 내부로 이동
href : 이동 주소
target="_blank" : 새 탭 또는 새 창에서 열기
href="#top" : id="top" 위치로 이동

예)
<a href="#top">맨 위로</a>

3절. 특수문자
&lt; : <
&gt; : >
&amp; : &
&nbsp; : 줄바꿈되지 않는 공백

cf. 제목은 글자 크기보다 내용의 단계에 맞게 선택.
ins와 del은 단순 밑줄·취소선보다 변경 의미가 우선.
