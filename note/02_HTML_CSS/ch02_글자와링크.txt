2장  글자와 링크 태그


1절  글자 구조

h1부터 h6 → 내용의 단계에 맞는 제목
p → 문단
br → 줄바꿈
hr → 주제 전환
strong → 중요한 내용
b와 i → 주의를 끌거나 일반 문장과 구별할 내용
sup와 sub → 위 첨자와 아래 첨자
ins와 del → 추가된 내용과 삭제된 내용
span → 문장 일부를 묶어 스타일 적용


2절  링크

a → 다른 페이지나 문서 내부로 이동
href → 이동할 주소
target → 링크를 열 위치
문서 내부 이동은 대상 요소의 id를 사용한다.


3절  특수문자

&lt; → 여는 꺾쇠
&gt; → 닫는 꺾쇠
&amp; → 앰퍼샌드
&nbsp; → 줄바꿈되지 않는 공백
