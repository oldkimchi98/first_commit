5장  단위와 박스 모델


1절  단위

px → CSS 픽셀 단위
% → 속성별 기준에 대한 비율
em → 글꼴 크기를 기준으로 하는 상대 단위
pt → 인쇄 등에 사용하는 단위


2절  박스 구조

내용 → padding → border → margin
width와 height → 너비와 높이
padding → 내용과 테두리 사이 여백
border → 테두리
margin → 테두리 바깥 여백
border-radius → 모서리 둥글기


3절  크기와 여백 계산

box-sizing → 너비와 높이의 계산 방식
content-box → 지정 크기에 padding과 border가 추가됨
border-box → 지정 크기에 padding과 border가 포함됨
margin은 두 방식 모두 크기에 포함되지 않는다.
여백 값 4개 → 위 → 오른쪽 → 아래 → 왼쪽
여백 값 2개 → 위아래 → 좌우
