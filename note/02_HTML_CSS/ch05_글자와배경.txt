5장  글자와 배경


1절  글자

font-family → 글꼴과 대체 글꼴
font-size → 글자 크기
font-weight → 굵기
font-style → 기울임 등 글자 스타일
color → 글자색
text-align → 글자 정렬
text-decoration → 밑줄 등 장식
line-height → 한 줄의 높이


2절  배경

background-color → 배경색
background-image → 배경 이미지
background-repeat → 반복 방식
background-position → 이미지 위치
background-size → 이미지 표시 크기
url() → 파일 경로 지정
rgba() → 색상과 투명도 지정


3절  글꼴 연결

@font-face → 글꼴 파일 등록
@import → 외부 CSS 가져오기
상대 경로는 CSS 파일 위치가 기준이다. 글꼴 로딩에 실패하면 뒤의 대체 글꼴을 사용한다.
