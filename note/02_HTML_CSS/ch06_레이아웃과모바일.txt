6장  레이아웃과 모바일


1절  화면 구조

상단 메뉴 → 콘텐츠 영역 → 하단 정보
gnb → 상단 공통 메뉴
lnb → 주요 메뉴
banner → 배너 영역
product → 상품 목록
footer → 회사 정보와 저작권


2절  배치의 핵심

margin의 auto → 고정 너비 영역을 가로 가운데 배치
float → 요소를 띄워 배치
clear → float 아래로 구역 배치
box-sizing의 border-box → 지정 너비에 테두리와 안쪽 여백 포함
display의 flex → 메뉴와 버튼 배치
display의 grid → 카드와 지표를 행과 열로 배치
gap → 요소 사이 간격


3절  모바일 대응

viewport → 모바일 표시 영역 설정
device-width → 기기 너비를 표시 영역의 기준으로 사용
@media → 화면 너비 등 조건에 따라 스타일 변경
고정 너비를 사용할 때 작은 화면의 가로 넘침을 확인한다.
