12장  fetch와 비동기 처리


1절  핵심 용어

비동기 처리 → 응답을 기다리는 동안 다른 작업을 진행하는 방식
Promise → 나중에 완료되거나 실패할 작업의 결과를 나타내는 객체


2절  필수 함수와 속성

fetch() → HTTP 요청을 보내고 Promise 반환
then() → 완료 결과의 처리 연결
catch() → 실패 처리
response.ok → HTTP 성공 상태 여부
response.status → HTTP 상태 코드
response.text() → 응답 본문을 문자열로 읽기
URLSearchParams → 쿼리 문자열 생성


3절  처리 흐름

입력값 확인 → 요청 → 응답 상태 확인 → 본문 읽기 → 화면 갱신
404나 500 응답도 fetch 자체는 완료될 수 있으므로 response.ok를 확인한다.
