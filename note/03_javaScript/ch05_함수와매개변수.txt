5장  함수와 매개변수


1절  함수 작성 방식

함수 선언 → function으로 이름 있는 함수 정의
함수 표현식 → 함수를 값으로 만들어 변수에 저장
화살표 함수 → 함수를 짧게 표현하는 방식. 일반 함수와 this 처리 방식이 다름
일반적인 함수 선언은 선언 위치 앞에서 호출할 수 있다. 함수 표현식은 변수 초기화 이후 호출한다.


2절  입력과 결과

매개변수 → 함수가 받는 값의 이름
인수 → 호출할 때 전달하는 실제 값
return → 결과 반환과 함수 종료
기본값 → 인수가 생략되거나 undefined일 때 사용
나머지 매개변수 → 여러 인수를 배열로 받음
반환값을 지정하지 않은 일반 함수는 undefined를 반환한다.


3절  범위

지역변수 → 함수나 블록 안에서 사용하는 변수
내부함수 → 함수 안에 작성한 함수
