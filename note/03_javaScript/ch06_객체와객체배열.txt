6장. 객체와 객체 배열

1절. 객체
객체 : 관련 속성과 메서드를 묶은 값
속성 : 객체가 가진 데이터
메서드 : 객체가 가진 함수

예)
const student = {
    name: "홍길동",
    kor: 90,
    eng: 80,
    getSum(){ return this.kor + this.eng; }
};

2절. 접근과 변경
student.name : 점으로 속성 접근
student["name"] : 대괄호로 속성 접근
student.age = 20 : 속성 추가·수정
delete student.age : 속성 제거
this : 호출 방식에 따라 정해지는 대상

3절. 객체 배열
[{name:"홍",score:90}, {name:"김",score:80}]
forEach() : 학생별 내용 출력
sort() : 점수 등을 기준으로 정렬
toString() : 객체의 문자열 표현을 정의하는 메서드

cf. 객체를 복사 없이 다른 변수에 대입하면 같은 객체 참조.
배열의 항목과 객체의 속성을 구분해서 접근.
