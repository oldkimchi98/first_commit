6장  객체와 객체 배열


1절  객체 구조

객체 → 관련 데이터와 함수를 묶은 값
속성 → 객체가 가진 데이터
메서드 → 객체가 가진 함수
this → 함수의 호출 방식에 따라 정해지는 대상


2절  접근과 변경

점 표기법 → 속성 이름으로 접근
대괄호 표기법 → 문자열이나 변수로 속성에 접근
대입 → 속성 추가 또는 수정
delete → 속성 제거
복사 없이 다른 변수에 대입하면 같은 객체를 참조한다.


3절  객체 배열

객체 배열 → 여러 객체를 항목으로 담은 배열
forEach() → 각 객체에 대해 함수 실행
sort() → 기준에 따라 객체 순서 정렬
toString() → 객체의 문자열 표현
배열의 항목을 먼저 찾고 해당 객체의 속성에 접근한다.
