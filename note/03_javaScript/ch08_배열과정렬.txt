8장  배열과 정렬


1절  필수 메서드

length → 배열 길이
join() → 항목을 문자열로 연결
slice() → 일부 항목을 새 배열로 복사
sort() → 원본 배열 정렬
reverse() → 원본 배열의 순서 반전


2절  정렬 기준

sort()에 비교함수가 없으면 기본적으로 문자열 기준으로 정렬한다.
숫자는 비교함수의 반환값으로 순서를 정한다. 음수는 앞에, 양수는 뒤에, 0은 같은 순서 기준을 뜻한다.


3절  배열 복사

slice()와 Array.from()과 펼침 문법 → 얕은 복사
얕은 복사 → 배열은 새로 만들지만 내부 객체는 공유
slice()는 원본을 바꾸지 않는다. sort()와 reverse()는 원본을 바꾼다.
