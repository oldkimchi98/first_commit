8장. 배열과 정렬

1절. 기본
length : 배열의 길이
join(구분자) : 항목을 문자열로 연결
slice(시작,끝) : 일부 항목을 새 배열로 복사
sort(비교함수) : 원본 배열 정렬
reverse() : 원본 배열의 순서 반전

2절. 숫자 정렬
arr.sort((a,b)=>a-b) : 오름차순
arr.sort((a,b)=>b-a) : 내림차순

예)
const scores = [52,100,12,98,32];
scores.sort((a,b)=>b-a);
const top3 = scores.slice(0,3); // [100,98,52]

3절. 배열 복사
arr.slice() : 얕은 복사
[...arr] : 얕은 복사
Array.from(arr) : 얕은 복사

cf. sort()에 비교함수가 없으면 기본적으로 문자열 기준.
slice()와 sort()의 원본 변경 여부를 구분.
복사된 배열 안에 객체가 있으면 그 객체는 공유됨.
위 세 방식은 중첩 객체까지 복사하는 깊은 복사가 아님.
