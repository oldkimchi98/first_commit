9장. 브라우저 객체 모델

1절. window
window : 브라우저의 전역 객체
open(주소,이름,옵션) : 새 창·탭 열기
close() : 스크립트로 연 창 등의 닫기
opener : 현재 창을 연 창 참조

2절. location
location.href : 현재 주소 읽기·다른 주소로 이동
location.reload() : 현재 페이지 새로고침
location.assign() : 지정 주소로 이동
location.replace() : 현재 방문 기록을 교체하며 이동

3절. history
history.back() : 이전 기록
history.forward() : 다음 기록
history.go(숫자) : 지정한 만큼 기록 이동

수업 예)

자식 창의 값을 부모 창 입력창으로 전달
화면 이동과 이전 페이지로 돌아가기
