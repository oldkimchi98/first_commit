8장  문자열 메서드


1절  길이와 위치

length → 문자열 길이
indexOf() → 처음 나타난 위치. 없으면 -1
lastIndexOf() → 마지막으로 나타난 위치
substring() → 지정 범위의 문자열 추출. 끝 위치는 제외


2절  변환

trim() → 앞뒤 공백 제거
toUpperCase()와 toLowerCase() → 대문자와 소문자로 변환
replace() → 찾은 부분 변경
replaceAll() → 일치하는 부분 모두 변경
concat() → 문자열 연결


3절  핵심 주의점

문자열을 변환하는 메서드는 새 문자열을 반환한다. 원본 변수의 값을 바꾸려면 재할당한다.
substring()의 끝 위치는 결과에 포함되지 않는다.
