11장  이벤트와 입력 검사


1절  이벤트 등록

이벤트 → 클릭이나 입력처럼 브라우저에서 발생하는 동작
onclick → 클릭 처리 함수 지정
addEventListener() → 이벤트 처리 함수 등록
removeEventListener() → 같은 함수 참조로 등록 해제
DOMContentLoaded → DOM 구성이 끝난 시점
load → 페이지와 관련 리소스 로딩 완료


2절  주요 이벤트

click → 클릭
keyup → 키를 놓음
input → 사용자 입력값 변경
change → 선택이나 입력 변경이 확정됨
submit → 양식 제출


3절  입력 검사 흐름

입력값 확인 → 조건 검사 → 오류 안내 또는 제출
preventDefault() → 제출이나 링크 이동 등의 기본 동작 방지
focus() → 입력 요소로 초점 이동
addEventListener()에서는 return false만으로 제출이 막히지 않는다.
