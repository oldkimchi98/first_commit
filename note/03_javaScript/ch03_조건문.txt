3장  조건문


1절  if

if → 조건이 참일 때 실행
else if → 앞 조건이 거짓이면 다음 조건 확인
else → 앞 조건이 모두 거짓일 때 실행


2절  switch

switch → 값에 맞는 case 실행
case → 비교할 값 지정
break → switch에서 빠져나옴
default → 맞는 case가 없을 때 실행
break가 없으면 다음 case도 이어서 실행될 수 있다.


3절  짧은 조건

삼항 연산자 → 조건에 따라 두 값 중 하나 선택
&& → 앞의 값이 참으로 해석되면 뒤의 식 평가
|| → 앞의 값이 거짓으로 해석되면 뒤의 식 평가
숫자 입력은 빈 값과 취소값과 NaN을 먼저 확인한다.
