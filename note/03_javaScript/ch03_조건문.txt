3장. 조건문

1절. if
if(조건) : 참일 때 실행
else if(조건) : 앞 조건이 거짓일 때 다음 조건 확인
else : 앞 조건들이 모두 거짓일 때 실행

예)
if(score >= 80){
    console.log("통과");
}else{
    console.log("재확인");
}

2절. switch
switch(값) : 값에 맞는 case 실행
case : 비교할 값
break : switch 탈출
default : 맞는 case가 없을 때 실행

3절. 짧은 조건
조건 ? 값1 : 값2 : 참이면 값1, 거짓이면 값2
조건 && 동작 : 조건이 참이면 뒤의 식 평가
조건 || 동작 : 조건이 거짓이면 뒤의 식 평가

수업 예)
시간에 따라 인사말·이미지 변경
요일에 따라 배경색 변경
나머지 연산 %로 짝수·홀수 구분

cf. 숫자 입력의 빈 값·취소·NaN을 먼저 확인.
switch에 break가 없으면 다음 case도 이어서 실행될 수 있음.
