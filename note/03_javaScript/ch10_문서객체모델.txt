10장  문서 객체 모델 DOM


DOM → HTML 문서를 요소와 노드로 다루는 구조


1절  요소 찾기

getElementById() → id로 요소 하나 찾기
querySelector() → CSS 선택자로 첫 요소 찾기
querySelectorAll() → CSS 선택자로 요소 목록 찾기
querySelector()는 대상이 없으면 null을 반환한다. querySelectorAll() 결과는 NodeList다.


2절  요소 생성과 제거

createElement() → 요소 생성
appendChild() → 자식 노드 추가
removeChild() → 자식 노드 제거


3절  내용 변경

textContent → 텍스트 읽기와 변경
innerHTML → 내부 HTML 읽기와 변경
value → 입력 요소의 현재 값
style → 요소의 스타일 변경
setAttribute() → 속성 지정
사용자 입력을 단순 표시할 때는 textContent를 사용한다.
