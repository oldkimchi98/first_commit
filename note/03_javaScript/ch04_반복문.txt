4장  반복문


1절  반복 방식

for → 초기값과 조건과 증감으로 반복 제어
while → 조건이 참인 동안 반복
do while → 먼저 한 번 실행한 뒤 조건 확인


2절  배열과 객체 순회

for of → 배열 등의 값을 차례로 읽기
for in → 객체의 열거 가능한 속성 이름 읽기
forEach() → 배열의 항목마다 함수 실행
일반 객체는 기본적으로 for of의 대상이 아니다.


3절  반복 제어

break → 반복문에서 빠져나옴
continue → 현재 회차를 건너뛰고 다음 회차 실행
forEach()는 break로 중단할 수 없다.
