2장  변수와 자료형과 연산자


1절  변수

var → 함수 범위. 같은 범위에서 재선언 가능
let → 블록 범위. 재할당 가능
const → 블록 범위. 재할당 불가
const로 만든 배열과 객체의 내부 내용은 변경할 수 있다.


2절  자료형

string → 문자열
number → 숫자
boolean → 참 또는 거짓
undefined → 값이 지정되지 않음
null → 값이 없음을 명시
object → 객체. 배열도 객체에 포함
typeof → 자료형 확인


3절  변환과 연산

Number() → 숫자로 변환
parseInt() → 문자열 앞부분을 정수로 해석
Boolean() → 논리값으로 변환
== → 형 변환을 포함한 비교
=== → 자료형과 값을 함께 비교
+= → 누적 대입
&&와 ||와 ! → 논리 연산
템플릿 리터럴 → 문자열 안에 변수나 식을 넣는 방식
