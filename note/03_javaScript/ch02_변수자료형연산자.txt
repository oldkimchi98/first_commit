2장. 변수·자료형·연산자

1절. 변수
var : 함수 범위, 같은 범위에서 재선언 가능
let : 블록 범위, 재할당 가능
const : 블록 범위, 재할당 불가

2절. 자료형
string : 문자열 / number : 숫자
boolean : true, false
undefined : 값이 지정되지 않은 상태
null : 값이 없음을 명시
object : 객체 (배열도 객체)
typeof : 값의 자료형 확인

3절. 변환과 연산
Number() : 숫자로 변환
parseInt() : 문자열 앞부분을 정수로 해석
Boolean() : 논리값으로 변환
== : 형 변환을 포함한 비교
=== : 자료형과 값 비교
+= : 누적 대입
&&, ||, ! : 논리 연산
`이름은 ${name}` : 템플릿 리터럴

cf. const 배열의 항목은 변경 가능. 변수 자체의 재할당이 금지됨.
false로 해석되는 값 예 : 0, NaN, undefined, null, "".
빈 배열 []과 공백 문자열 " "는 true.
prompt 취소값 null과 문자열 "null"은 다름.
