8장  날짜와 정규표현식


1절  날짜

Date → 날짜와 시간을 다루는 객체
getFullYear() → 연도
getMonth() → 월. 0부터 11까지
getDate() → 일
getDay() → 요일. 0은 일요일
getHours() → 시
getTime() → 기준 시점부터의 밀리초
여러 숫자 인수로 날짜 객체를 생성할 때 월도 0부터 시작한다.


2절  숫자 계산

Math.abs() → 절댓값
Math.floor()와 Math.ceil() → 내림과 올림
Math.round() → 반올림
Math.trunc() → 소수 부분 제거


3절  정규표현식

정규표현식 → 문자열이 특정 규칙에 맞는지 나타내는 패턴
test() → 패턴 일치 여부 확인
^와 $ → 시작과 끝
\d와 \s → 숫자와 공백 문자
\w → 일반적인 기본 사용에서 영문자와 숫자와 밑줄
{n,m} → 반복 횟수 범위
+와 * → 한 번 이상과 0번 이상 반복
