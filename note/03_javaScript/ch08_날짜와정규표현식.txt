8장. 날짜와 정규표현식

1절. Date
new Date() : 현재 시점의 날짜 객체
getFullYear() : 연도
getMonth() : 월 (0~11)
getDate() : 일
getDay() : 요일 (0은 일요일)
getHours() : 시 (0~23)
getTime() : 1970년 기준 시점부터의 밀리초
toLocaleString() : 지역 형식의 날짜·시간 문자열

2절. 계산
Math.abs() : 절댓값
Math.floor() : 내림
Math.ceil() : 올림
Math.round() : 반올림
Math.trunc() : 소수 부분 제거

3절. 정규식
/pattern/ : 정규식 작성
test(문자열) : 패턴 일치 여부
^, $ : 시작·끝
\d : 숫자 / \s : 공백 문자
\w : 영문자·숫자·밑줄 (일반적인 기본 사용)
{n,m} : n~m회 / + : 1회 이상 / * : 0회 이상

cf. 날짜 생성 시 월도 0부터 시작.
두 시점의 24시간 차이와 달력상 날짜 차이는 구분.
문자열 전체를 검사할 때 시작·끝 조건 확인.
