1장  JavaScript 출력과 연결


1절  연결

script → HTML 안에 코드 작성 또는 외부 JavaScript 연결
src → 외부 파일 경로
defer → 외부 일반 스크립트를 문서 파싱 후 실행


2절  필수 출력 함수

console.log() → 개발자 도구 콘솔 출력
alert() → 안내 대화상자
confirm() → 확인 여부를 true 또는 false로 반환
prompt() → 입력 문자열 반환. 취소하면 null
화면의 텍스트 변경에는 textContent를 사용한다.


3절  주석

// → 한 줄 주석
/* */ → 여러 줄 주석
