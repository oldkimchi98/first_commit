5장  콜백 함수와 타이머


1절  콜백

콜백 함수 → 다른 함수에 인수로 전달하는 함수
전달받은 함수가 필요한 시점에 콜백을 실행한다.
함수 이름을 전달하는 것과 함수를 즉시 호출하는 것은 다르다. 모든 콜백이 비동기로 실행되는 것은 아니다.


2절  필수 타이머 함수

setTimeout() → 일정 시간이 지난 후 한 번 실행 예약
setInterval() → 일정 간격으로 반복 실행 예약
clearTimeout() → 한 번 실행 예약 취소
clearInterval() → 반복 실행 예약 취소
시간 단위는 밀리초다. 타이머는 정확한 실행 시각을 보장하지 않는다.
